# Configarium

Personal [chezmoi](https://www.chezmoi.io/) configuration for macOS, Linux (including WSL), and Windows. It manages shell and terminal configuration without managing packages, runtimes, credentials, or agent content.

## Docs

- [Setup](docs/setup.md)
- [Layout](docs/layout.md)
- [Third-Party Notices](THIRD_PARTY_NOTICES.md)
- [Security](SECURITY.md)

Before applying a change, run `chezmoi diff`; use `chezmoi apply` only after reviewing the result.
